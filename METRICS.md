# Metrics

## North Star Metric

**Audits with shared results per week.**

Why not "audits completed"? Because an audit that isn't shared generates zero organic distribution. Why not "revenue" at this stage? Because the tool is a lead-generation asset, not a SaaS product. A shared result means: the user found enough value to screenshot or link it, someone else saw it, and the distribution flywheel spun one rotation. Every share is 5-50 new top-of-funnel visits.

## 3 Input Metrics That Drive the North Star

1. **Audit completion rate** — Visits → audits completed. If this is below 40%, the form is too complex or intimidating. Target: 50%+ from cold traffic.

2. **Share rate** — Audits completed → shared (either via copy-link button or organic screenshot). If this is below 10%, the results aren't compelling enough to share. Target: 15-20%.

3. **Savings significance rate** — Audits with >$100/month savings as a percentage of total. If this drops below 30%, the tool isn't finding real savings, and shares will dry up. Target: 40%+ of audits show meaningful savings.

## What I'd Instrument First

1. **Event tracking on the audit form:** Tool selected, plan selected, form abandoned (analytics on which tools are most common helps prioritize pricing updates)

2. **Event tracking on results page:** Copy-link clicks, social share clicks, email capture form views vs submissions, Credex CTA clicks (for high-savings audits)

3. **Referrer tracking:** Where did the user come from? (HN, Twitter, Reddit, direct, search — this tells us which GTM channels are working)

4. **Time-to-complete:** How long from form start to audit results? If >90 seconds, the form needs simplification.

5. **Return rate:** Do users come back and re-run the audit? If yes, they're tracking their spend over time — this is a sticky feature, not a one-time utility.

## What Number Triggers a Pivot

**Pivot trigger:** If after 60 days, audit-to-consultation conversion is below 0.3% (3 consultations per 1,000 audits), the tool is not functioning as a lead-gen asset — it's just a free utility.

**Pivot options in that scenario:**
- Add a paid tier ($29 one-time for PDF export, benchmarking, or API access)
- Sell anonymized aggregate data on AI tool spending trends (with consent)
- Pivot from lead-gen to a standalone SaaS tool with subscription pricing
- Sunset the tool and repurpose the audit engine as an internal Credex sales enablement tool (sales team runs audits manually during calls)

**Metric to watch before pivoting:** Share rate. If share rate is high (20%+) but conversion is low, the tool has product-market fit as a utility — just not as a Credex funnel. That's a different problem than "nobody wants this."
